### combat.bi.no.clankerslop

I liked the concept of the combat.ai plugin by Zuckung, but I didn't like the AI image. So I made a plugin to change it. All images are 100% real, taken and edited by me personally. No 3D models, and NO AI.

The image is intentionally more boring and unassuming. I believe that this fits the feel of the game better. If you don't like it don't download it.

Needless to say you need Zuckung's combat.ai plugin for this to work.<br>
